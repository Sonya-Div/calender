## 🇬🇧 English

A responsive, functional web-based calculator designed with a sleek iOS-inspired user interface. This project was built to practice foundational frontend web development skills, specifically focusing on vanilla JavaScript logic and dynamic layout design using CSS Grid and Flexbox.

### 🚀 Features
* **Full Math Logic**: Perform addition, subtraction, multiplication, and division.
* **Smart Backspace (⌫)**: Delete the last entered character directly from the display container.
* **Advanced Operations**: Toggle numbers between positive/negative (`+/-`) and calculate percentages (`%`).
* **Fully Responsive**: Optimized for all screen sizes, adapting beautifully to mobile devices and tablets using Media Queries.
* **Interactive UI**: Smooth hover and active states giving a tactile button press feeling.

### 🛠️ Built With
* **HTML5**: Structured semantic layout.
* **CSS3**: Styled with CSS Grid, Flexbox, and Media Queries for a seamless mobile experience.
* **JavaScript (Vanilla)**: Clean logic handling memory inputs, string evaluations, and error handling.

## 🇸🇦 العربية

آلة حاسبة تفاعلية مصممة بأسلوب عصري مستوحى من واجهة نظام iOS الشهيرة وتدعم التجاوب الكامل مع الهواتف الذكية. تم بناء هذا المشروع لتطبيق أساسيات تطوير الويب، مع التركيز على منطق الجافاسكريبت وبناء التنسيقات المرنة باستخدام CSS Grid و Flexbox.

### 🚀 المميزات
* **العمليات الأساسية**: دعم الجمع، الطرح، الضرب، والقسمة بالكامل.
* **زر التراجع الذكي (⌫)**: إمكانية حذف آخر رقم تم إدخاله مباشرة من جانب الشاشة العلوية.
* **ميزات متقدمة**: عكس إشارة الأرقام بين الموجب والسالب (`+/-`) وحساب النسبة المئوية (`%`).
* **تجاوب كامل مع الموبايل**: واجهة مرنة تتكيف وتملأ شاشات الهواتف الذكية بسلاسة باستخدام الـ Media Queries.
* **تفاعل حركي احترافي**: تأثيرات بصرية عند مرور الماوس والضغط تعطي شعوراً حقيقياً بالأزرار الثنائية والثلاثية الأبعاد.

### 🛠️ التقنيات المستخدمة
* **HTML5**: لبناء الهيكل المنظم للآلة الحاسبة والشاشة والأزرار.
* **CSS3**: للتصميم والتوزيع الشبكي المرن وضمان مرونة الهواتف.
* **JavaScript**: لبرمجة منطق الحسابات، معالجة النصوص، والتحكم التفاعلي بالشاشة.
